一、适用操作系统与硬件环境
1. 操作系统: Windows 7 SP1 (x86/x64)、Windows 10、Windows 11、Windows Server 全系列
2. 运行环境: 原生支持 .NET Framework 4.8 AnyCPU，单文件绿色独立运行，无需安装运行时
3. 资源开销: 
   - 内存占用: 8MB ~ 12MB (严格受控)
   - CPU 占用: 日常 < 0.5%
   - 磁盘 I/O: 0 KB/s (纯内存操作链环形队列，故障前完全不磨损硬盘)

二、快速安装部署方法
【方法 1：科室极速部署（推荐）】
1. 解压整个文件夹；
2. 鼠标右键点击【一键安装(以管理员身份运行).bat】，选择「以管理员身份运行」；
3. 脚本会自动完成权限配置、文件拷贝（至 C:\Program Files\HIOps\Sensor\）以及注册 Windows 开机自启；
4. 任务栏右下角出现【HIOps 医院运维小助手】图标，表示安装成功并已开始静默看护。

【方法 2：信息中心批量静默分发 (奇安信天擎 / 域控 GPO / 终端管家)】
推荐分发方式（二选一）：
方式 A（推荐）：直接下发单文件安装包
   - 运行程序: HIOps-EndpointSensor-Setup.exe
   - 运行参数: /S  （大写S，代表静默无感安装，不弹窗）
方式 B：下发解压包并执行脚本
   - 运行命令: install.bat

三、下发失败如何获取原因与排查？
1. 查看客户端本地安装日志:
   - 日志路径: C:\ProgramData\HIOps\install.log
   - 日志记录了提权状态、.NET 版本检测、文件释放、任务计划注册输出及异常堆栈。
2. 运行一键排障诊断程序:
   - 客户端双击运行【一键排障诊断.bat】(或 diagnose.bat)
   - 5秒内全自动检查：管理员权限、.NET运行时、文件释放、计划任务、进程保活、中台网络出站(114.30:5080)连通性。
3. 奇安信/管家控制台查看:
   - 退出代码 0: 安装成功
   - 退出代码 1: 执行异常（请看 install.log）
   - 退出代码 1260 / 拒绝访问: 杀毒软件主防拦截（需在奇安信加白 HIOps-EndpointSensor-Setup.exe）
   - 提示超时/无响应: 下发参数漏填了 /S 导致后台等待弹窗。

四、临床医护使用功能
1. 故障静默自动上报:
   当医生工作站发生程序未响应假死超过 5 秒、闪退崩溃时，探针自动抓取前序 60 秒因果操作链，生成《确定性复现包》发送至信息中心，无需医生打电话报修。
2. 桌面运维小助手:
   右击任务栏托盘小助手图标：
   - 点击【一键修复打印机/清理假死队列】: 5 秒内静默清理堵塞作业并恢复出纸；
   - 点击【一键清理本地缓存】: 清理卡死的临时文件与浏览器缓存；
   - 点击【上报卡顿】: 立即冻结当前操作并呼叫信息中心支援。

五、卸载方法
如需卸载，右键点击【一键卸载.bat】，选择「以管理员身份运行」，将自动停止进程、删除开机自启并清理文件。
